 
data-description  <h2>File descriptions</h2>
<ul>
<li><strong>dataset11-30week.csv</strong> - the training set. **vsetv_id** is the same as **channel_id** in export_arh_*.csv files.</li>
<li><strong>export_arh_10-19.csv</strong> - supplemental information about train data (TV program schedule). Contains  tv_show_id - you have to predict 5 of these for the submission.csv user_ids. Note: tv_show_id = 0 stands for irrelevant TV shows, drop them!</li>
<li><strong>export_arh_20-30.csv</strong> - supplemental information about train data (TV program schedule). Contains  tv_show_id - you have to predict 5 of these for the submission.csv user_ids. Note: tv_show_id = 0 stands for irrelevant TV shows, drop them!</li>
<li><strong>export_arh_31-42.csv</strong> - supplemental information about test data (TV program schedule). Contains  tv_show_id - you have to predict 5 of these for the submission.csv user_ids. Note: tv_show_id = 0 stands for irrelevant TV shows, drop them!</li>
<li><strong>submission.csv</strong> - a sample submission file in the correct format. Substitute 5 zeros with 5 predicted tv_show_ids for each user!</li>
</ul>
<h2>Train data fields</h2>
<ul>
<li><strong>user_id</strong> - an anonymous id unique to a given user</li>
<li><strong>vsetv_id</strong> - the id of a channel (equal to **channel_id** in export_arch_*.csv)</li>
<li><strong>start_time</strong> - start time of channel being watched</li>
<li><strong>end_time</strong> - end time of channel being watched</li>
<li><strong>duration</strong> - duration of channel being watched</li>
</ul>
<h2>Supplemental information data fields</h2>
<ul>
<li><strong>channel_id</strong> - Channel ID</li>
<li><strong>channel_title</strong> - Channel title</li>
<li><strong>start_time</strong> - Show start time</li>
<li><strong>duration</strong> - Duration in seconds</li>
<li><strong>tv_show_title</strong> - Title in the TV program</li>
<li><strong>tv_show_id</strong> - The identifier of a TV show or movie in the TV program database. It is not related to the base of films. int stands for a TV show episode and 0 for films</li>
<li><strong>tv_show_category</strong> - TV Show Category</li>
<li><strong>tv_show_genre_1</strong> - TV Show Genre 1</li>
<li><strong>tv_show_genre_2</strong> - TV Show Genre 2</li>
<li><strong>tv_show_genre_3</strong> - TV Show Genre 3</li>
<li><strong>year_of_production</strong> - The period of release or the year of production, if it ends in - means to the current moment.</li>
<li><strong>director</strong> - Film director.</li>
<li><strong>actors</strong> - Movie Actors or TV presenters.</li>
</ul>

<p>Test data contains user's tv program preferences for the next 12 weeks (weeks 31-42). Private/public test data is split BY USERS (50/50) - not by time. Every user from the solution has strictly 5 preferred TV programs, sorted ASC from the most preferred (#1) - has the largest number of views - to the least preferred (#5) - has the lowest number of views among top 5 TV programs FOR EACH USER</p>

<p>How expected solution file (stuff you have to predict) was made</p>
<ul>
<li>all entries with tv_show_id = 0 were removed from TV program schedule files</li>
<li>for each user and each TV show user screen time (time user watched the show divided by total duration of the show) was calculated. Only TV shows with high screen time (>= 0.8) were taken into account.</li>
<li>for each user high-screen time TV shows frequency was calculated</li>
<li>for each user **strictly** 5 most frequent TV shows were selected DESC (#1 is the most frequent, #5 is the least frequent amongst top 5) - order matters!</li>
<li>You have to guess 5 (space-separated) tv_show_ids for each user - fill submission.csv</li>
</ul>
